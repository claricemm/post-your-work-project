# BikeShare Data Analysis

This project analyzes **bike-sharing data** from New York City. Users can interactively explore the data by selecting a city, month, and day of the week. The program then **calculates and displays statistics** about travel times, stations, trip durations, and user demographics using Python and the pandas library.
## Information about how to use your project

_Installation_
 1. Prerequisites: 
 Before running the project, make sure you have: Python 3.8 or later, pip (Python package manager)
 
 2. Install Dependencies: 
 Install the required Python package: 
 'pip install pandas'

_Set up_
 
 1. Clone this repository: 'git clone https://github.com/claricemm/post-your-work-project'
 
 2. Navigate to the project directory: 'cd post-your-work-project'

_Common Issues_
 
 **ModuleNotFoundError** 
 No module named 'pandas'
 To do: Install pandas: 'pip install pandas'

 **FileNotFoundError**
 Make sure the following file are in the same directory as bikeshare.py: new_york_city.csv
